# INDUSTRIAS
MANIFIESTO: La IA no tiene el mismo propósito en todas las industrias, pero todas comparten el patrón: Información + Reglas + Repetición + Acciones.
SECTORES: Finanzas, Legal, Salud, Manufactura, Logística, Retail, Seguros, Educación, RRHH, Ventas, Energía, Software.
ENFOQUE: No se trata de "poner IA en todos lados". Es software para reglas deterministas, IA para interpretar lenguaje ambiguo, e infraestructura para conectar todo.
